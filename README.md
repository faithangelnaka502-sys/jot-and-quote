# Jot & Quote

Notes and quotes, side by side.

## Deploying to Vercel (get your live link)

1. Create a new repository on GitHub (e.g. `jot-and-quote`).
2. Upload all files in this folder to that repository (keep the folder structure — `src/`, `public/`, and the config files all need to stay where they are).
3. Go to [vercel.com](https://vercel.com) and sign up using your GitHub account.
4. Click **Add New → Project**, then select your `jot-and-quote` repository.
5. Vercel will auto-detect it as a Vite project — leave the default settings and click **Deploy**.
6. After a minute you'll get a live link like `jot-and-quote.vercel.app`.

## Adding it to your phone's home screen

1. Open your Vercel link on your phone in Chrome (Android) or Safari (iPhone).
2. **Android:** tap the three-dot menu → "Add to Home screen".
   **iPhone:** tap the Share icon → "Add to Home Screen".
3. Confirm the name and tap Add — it'll now open full-screen from your home screen like a real app.

Your notes are stored right on your device (in the browser's local storage), so nothing needs a server or account to work.
